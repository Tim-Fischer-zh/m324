# Lernjournal

## 13.11.2026 Tag 1
CALMS, steht für Culture, Automation, Lean, Measurement, Sharing.
Wobei Lean oft als optional betrachtet wird, deswegen mehrheitlich CAMS.

### Culture
Zusammenarbeit im Team, unabhängig von den Rolen. Anstatt das Teams abgeschottet sind, arbeiten sie zusammen.
Kultur ist entscheidend weil nur in der Zusammenarbeit ein Feature oder Produkt effizient geshipped werden kann. Deswegen müssen die Teams organisatorisch zusammen arbeiten.

### Automation
"Möglichst viele Aufgaben automatisieren" wenige manuelle Schritte, möglichst viel Zeitsparen. Automatisierte Tests, Artefakte, Monitoring.
Automatisierung darf nicht mit == DevOps gesetzt werden.
CI/CD ist ein technischer Bestandteil, eine Teilmenge.

### Lean
Eliminierung von Waste. Alles ohne Mehrwert soll entfernt werden.
"In der Praxis bedeutet das, so viel Vertrauen in das Team und die Software zu haben, dass gut getestete Experimente auf Produktivsystemen durchgeführt werden können."

### Measurement
Entscheidungen treffen die basieren auf Metriken. Quantifizierbare Daten liefern. (Metriken)

### Sharing
Hauptpunkt von den anderen Lernen. Knowledge Sharing. Probleme und Lernerfahrungen dokumentieren und präsentieren.
Bei uns im Betrieb habe ich oft Präsentationen, momentan gerade über einen Monitoring Stack den ich implementiert habe.
